Flujo: el cliente la pide desde Mis pedidos → se aprueba o rechaza → al llegar el paquete se registra si cada pieza vuelve a venta (entra al inventario) → se reembolsa o se envía el cambio. El monto lo calcula el sistema con lo que se pagó y no se puede cambiar. Cada paso queda en la auditoría y el cliente recibe un correo.
