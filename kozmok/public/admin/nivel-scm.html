Nivel actual

Calculado a partir de datos reales del sistema, no de una lista marcada a mano: conforme se usa cada parte del módulo, el nivel avanza solo.

Checklist de avance

Fijar el nivel (administrador)

Por defecto el nivel se calcula solo con el checklist. Si la empresa evalúa su madurez de otra forma, aquí se puede fijar a mano y regresar al cálculo automático cuando se quiera.

Cómo se calcula

  • Inicial (0–1 puntos): procesos básicos, la cadena apenas se está armando.
  • En desarrollo (2–3 puntos): integración de procesos; ya hay proveedores y trazabilidad de movimientos.
  • Optimizado (4–5 puntos): procesos avanzados, con push y pull en uso, pedidos de reposición y reportes con ventas reales.
